# Homarrの使い方

## 利用者として使う

Homarrは、各サービスを開くための入口です。ファイルや本そのものを保存する場所ではありません。

1. [Homarr](http://localhost:7575/)を開きます。
2. 使いたいタイルを押します。
3. ログイン画面が出たら、案内に従ってログインします。
4. Homarrへ戻るときは、ブラウザーの戻るボタンを使います。

タイルが開かない場合は、接続手順にあるSSH転送とURLを確認します。サービスを直接使わず、まずHomarrから開くと、正しい入口を選べます。

## Androidで使う

Homarr専用のAndroidアプリは使わず、Androidのブラウザーで開きます。ブラウザーのメニューから **ホーム画面に追加** または **アプリをインストール** を選ぶと、すぐに開けるようになります。

ただし、`localhost`はそのAndroid端末自身を指します。パソコンでSSHトンネルを開いてもAndroidからは利用できません。Androidから使うときは、管理者が用意したHTTPSドメイン、VPN、またはTailscaleのURLを使います。

## 管理者としてボードを編集する

以下は、Homarrの管理権限を持つ人だけが行う操作です。一般利用者はタイルを編集できません。

1. `home`ボードを開きます。
2. 画面上部の **Edit mode**（編集モード）を押します。
3. **Add item** → **New Item** → **App** でタイルを追加します。
4. タイル右上の3点メニューから **Edit item** を開き、表示するアプリを選びます。
5. タイルを移動し、右下をドラッグしてサイズを調整します。
6. **Exit edit mode** を押して終了します。

タッチ操作で移動しにくいときは、タイルのメニューにある **Move / resize item** を使います。詳しくは[Homarr公式のボード編集手順](https://homarr.dev/docs/getting-started/after-the-installation/)を参照してください。

## サービスの名前やURLを変更する

管理対象のサービスリンクは`hub/apps.json`で管理しています。URLや表示名を継続的に変更する場合は、サーバー管理者がこのファイルを編集し、次のコマンドで反映します。

```bash
cd media-stack
sudo .hub-venv/bin/python hub/configure-homarr.py
```

画面上でURLだけを変更しても、後でこの反映処理を実行すると`apps.json`の内容に戻ります。タイルの位置やサイズは反映処理で変更しません。

不要なタイルを消す場合は、編集モードでタイルまたはアプリを削除します。設定ファイルから項目を消すだけでは、既存のタイルは自動削除されません。

## 日本語表示

Homarrの標準言語はサーバー側で日本語（`ja`）に設定しています。すでにブラウザーへ保存された個人設定がある場合は、プロフィールまたは設定の言語で**日本語**を選び、再読み込みしてください。

共通ログイン画面の言語は、ログイン画面の言語メニューまたはブラウザーの言語設定に従います。

## 管理者がログインできないとき

ローカル管理者の接続情報はサーバーの`runtime/access.json`にあります。このファイルのパスワードをチャットやGitへ貼り付けないでください。

SSOで管理する場合は、Authentikの`homarr-admins`グループに所属するアカウントを使います。一般利用者の`media-users`だけでは閲覧のみです。アカウントやグループの変更は[共通ログインの手順](sso.md)を参照してください。
