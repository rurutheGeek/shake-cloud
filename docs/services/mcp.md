# AIエージェントからクラウドを見る（MCP）

> **更新日** 2026-09-23 ・ **区分** 利用ガイド ・ **読む人** 利用者

**状態**: 読み取り専用のMCPサーバ（`cloud/mcp`）を dev-b でビルドし、opencode に登録済み。**読み取り専用キーを設定すると使えます。**

MCPは、AIエージェント（opencodeなど）に外部の道具を渡す仕組みです。このサーバを登録すると、エージェントが**クラウドAPIを読み取り専用で**呼べるようになります。**見るだけ**で、作成・起動・停止・削除はできません。書き込みはこれまでどおりポータル・CLI・Terraformです。

## 何を聞けるか

話しかけるだけで、エージェントが適切なツールを選んで調べます。

| 聞きたいこと | 質問の例 |
| --- | --- |
| VMの一覧・状態 | 「クラウドのVMを一覧して。停止中のものがあれば教えて」 |
| 1台の詳細 | 「media-01 のIPとスペックを教えて」 |
| 容量・上限 | 「メモリとストレージの空きは？ 今の上限も見せて」 |
| 操作履歴 | 「今日の操作履歴を見せて。削除はあった？」 |
| 起動元 | 「使えるイメージとISOを一覧して」 |
| SSH鍵 | 「登録されているSSH鍵の名前と指紋は？」 |
| 追加ディスク | 「アタッチされていないボリュームはある？」 |
| ファイアウォール | 「既定セキュリティグループのルールを見せて」 |
| S3 | 「バケットと、それぞれに許可されているキーを教えて」 |
| database・function | 「database と function の状態を一覧して」 |

**秘密値は返りません。** アクセスキーの秘密値、S3のsecret、DBパスワードはツールに出しません（DB資格情報の操作は意図的に公開していません）。

## 使い始める（opencode）

1. **読み取り専用のアクセスキーを用意します。** 管理者はポータル（<https://cloud.apextox.dpdns.org> → ログイン →「アクセスキー」）で権限「読み取り専用」を選んで発行します。開発者は自分で発行できます。
2. **鍵をファイルに保存します。** 改行を入れないのがポイントです。

```bash
printf %s 'sca_...' > ~/.config/opencode/shakecloud-mcp.key
chmod 600 ~/.config/opencode/shakecloud-mcp.key
```

3. **opencodeを再起動します。** 設定（`~/.config/opencode/opencode.jsonc`）には登録済みです。ツール一覧に `shakecloud_...` が出れば使えます。

登録の書式・ツール22個の一覧・鍵の作り直しは[管理者向けの手順](../operations/mcp.md)にあります。

## できないこと

- **作成・起動・停止・再起動・削除・コンソール・サイズ変更・上限変更・S3キー発行**はできません。ポータル・CLI・Terraformを使ってください。
- 読み取り専用キーで書き込みを頼むと、APIが 403 `AccessDenied` で拒否し、監査ログに残ります（キーが読み書き可でも、MCPには書き込みツールがありません）。

## 気をつけること

- **ツールはAIのコンテキストを消費します。** 使わないときは opencode の設定で無効化できます（`"tools": {"shakecloud*": false}`）。
- **呼び出しは監査ログに残ります。** `user_agent` が `shakecloud-mcp/0.1.0` なので、CLI・Terraformと区別できます。
- **回答はAIの要約です。** 正確な値が必要なときは、ポータルの「容量」「履歴」や `shakecloud` CLI で確認してください。
- APIは**家庭内LANのみ**です。外出先から使うにはVPN（準備中）が必要です。

## うまくいかないとき

| 症状 | 確認すること |
| --- | --- |
| opencode にツールが出ない | opencodeを再起動したか。設定の `mcp.shakecloud.enabled` が `true` か |
| サーバーが起動しない | 鍵ファイルが空でないか。改行が入っていないか（`printf %s` で保存） |
| 401 が返る | キーが間違っている・失効している。ポータルで確認して作り直す |
| 403 `AccessDenied` | 書き込みを頼んだ（読み取り専用キー）。ポータル・CLI・Terraformへ |
| 502・503 が返る | クラウドAPIが止まっている。管理者に連絡（`https://cloud.apextox.dpdns.org/healthz`） |
