# Home Assistantと家電の使い方（利用者向け）

Home Assistant（HA）は、家の家電の状態を見たり操作したり、自動化するための入口です。このページは日常的に使う人向けで、サーバーの操作は必要ありません。

## 入口とログイン

- 開く場所: <https://ha.apextox.dpdns.org>（**家庭内LANから**。宅外は未対応）
- ログイン: ログイン画面で **Login with Authentik** を選び、共通アカウント（招待制）でログインします。管理者用のローカルアカウントも残しています
- アカウントが無い場合は管理者に招待を依頼します（[共通ログインの使い方](identity.md)）
- スマートフォンのアプリからも同じアカウントで入れます（下の「Androidアプリ」を参照）

## 画面の見方

| 場所 | できること |
| --- | --- |
| 概要（Overview） | よく使う機器の状態確認と操作 |
| 履歴 / ログブック | いつ何が変わったかの確認 |
| 設定 → デバイスとサービス | 連携機器の一覧。追加・削除・再読み込みは管理者の作業 |
| マイページ | 自分の表示名・テーマ・通知などの設定 |

## いま連携しているもの

| 対象 | 方式 | できること | 現状 |
| --- | --- | --- | --- |
| SwitchBot（Hub Mini経由） | SwitchBot Cloud | 鍵の施錠状態、ドアセンサー、赤外線家電（エアコン・テレビ・照明など）の操作と状態 | 利用可（機種により対応範囲が異なります） |
| Eufy eufyCam S4（リビング） | eufy-security-ws（クラウド＋Push） | 状態、イベント・Push、イベント画像（HAへのイベント取り込みは確認中） | ログイン・デバイス一覧・Pushは動作。ライブ映像は現在不可（新しい方式への対応を検討中） |
| Eufy SmartTrack（T87B0） | 同上 | 状態（対応範囲は限定的） | 利用可 |
| プリンター Canon TS8430 | IPP | 印刷（[プリンターの使い方](printer.md)） | 利用可 |
| HAの標準機能 | 内蔵 | 買い物リスト、日の出/日の入り、音声合成（Google翻訳TTS） | 利用可 |

- **AlexaからHAの家電を操作する連携は見送りました（2026-09-12）**。SwitchBot・Eufyは各社のAlexaスキルで操作できます
- EufyのイベントがHAへ届くかは、現在確認を進めています。ライブ映像はカメラ側が新しい方式（WebRTC）のため、暫くはEufyアプリを使ってください

## 自動化

「ドアが開いたらスマートフォンへ通知」「日没に照明を点ける」などをHAで作れます。既定の自動化はありません。作ってほしいときは、きっかけ・時間帯・通知先・操作したい機器を管理者へ伝えてください。スマートフォンへの通知は、下のアプリの通知設定が必要です。

## Androidアプリ

公式の **Home Assistant** アプリを使います。

### インストールとサーバー追加

1. Google Playで「Home Assistant」をインストールします
2. サーバーURLに `https://ha.apextox.dpdns.org` を入力します
3. 証明書はLet's Encryptなので、そのまま接続できます

### ログイン

1. ログイン画面で **Login with Authentik** を選びます
2. 共通アカウントでログインすると、アプリへ戻ります
3. 戻らずに止まったときは、アプリの追加をやり直してください

### 通知

- 初回に求められたら通知を許可します
- 通知は**家庭内LANでの接続（ローカルプッシュ）**で届きます。**宅外（モバイル回線）では届きません**（VPNが未整備のため）
- 通知が来ないときは、Androidの設定で「Home Assistant」を**バッテリー最適化の対象外**にし、通知を許可してください

### 端末の情報を使う機能（任意）

位置情報・バッテリー残量などをHAへ送れます。オンにする項目だけ許可してください。

### アプリでできること・できないこと

| できること | できないこと |
| --- | --- |
| 家電の状態確認・操作、ダッシュボードの表示、自動化の実行、通知の受け取り | 宅外からの接続、Eufyカメラのライブ映像、Alexaからの音声操作 |

## 困ったとき

| 症状 | 対処 |
| --- | --- |
| つながらない | 家庭内LANか確認してください。スマートフォンがモバイル回線だとつながりません |
| ログインできない | 共通アカウントを確認し、それでもだめなら管理者へ連絡してください |
| アプリの通知が来ない | 通知の許可と、バッテリー最適化の対象外設定を確認してください |
| 機器の名前・操作先を変えたい | 管理者へ依頼してください |

## 注意

- アカウントの貸し借りはしないでください
- サーバーの再起動中は、HAと自動化も一時的に止まります
- 「設定 → デバイスとサービス」の追加・変更・削除は管理者の作業です
