# 日本語に切り替える

各サービスは日本語表示に対応しています。サービスを開いたあと、次の場所で言語を選びます。

| サービス | 日本語にする場所 |
| --- | --- |
| Homarr | プロフィールまたは設定の **Language** で **日本語** |
| Nextcloud | 右上のプロフィール → **設定** → **個人** → **言語** |
| Navidrome | **Personal** またはプロフィール → **Language** → **日本語** |
| Kavita | プロフィール → **Preferences** → **Language** → **日本語** |
| Vaultwarden | **設定** → **プリファレンス** → **言語** → **日本語** |
| Authentik | ログイン画面の言語メニュー。ログイン後は利用者設定 |
| MeTube | 現在の配備版は英語UI。ブラウザー翻訳を利用 |
| 手順書 | このサイト自体が日本語 |

## Homarrが英語のままのとき

この構成では、Homarrのサーバー側の標準言語を日本語（`ja`）にしています。すでに使ったブラウザーには以前の言語設定が保存されていることがあるため、次を試します。

1. Homarr右上のプロフィールまたは設定を開きます。
2. **Language** で **日本語** を選びます。
3. ブラウザーを再読み込みします。

別のブラウザーやシークレットウィンドウで日本語になる場合は、元のブラウザーに保存された個人設定が原因です。

## 共通ログイン画面が英語のとき

ログイン画面の言語メニューから**日本語**を選びます。言語メニューが見つからない場合は、Androidやブラウザーの優先言語を日本語にしてからページを再読み込みします。

## 注意

サービスによっては、管理者が設定した標準言語よりも、利用者ごとの保存済み設定が優先されます。日本語に切り替えても一部の固有名詞や管理画面だけ英語のまま残ることがあります。
