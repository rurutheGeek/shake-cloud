# ポケモン翻訳

> **更新日** 2026-09-27 ・ **区分** 利用ガイド ・ **読む人** 利用者

ポケモン・わざ・とくせい・どうぐ・タイプ・せいかくなどの用語を**公式名に固定して**
翻訳するツールです。海外の攻略サイトで「Earthquake」が「地震」、「Protect」が
「プロテクト」と訳されるような問題を避け、「じしん」「まもる」と訳します。
入口は <https://poke.apextox.dpdns.org>（家庭内LANから）。Homarrの
**ポケモン翻訳** タイルからも開けます。

## 2つの使い方

| | 翻訳サイト | 拡張機能 |
| --- | --- | --- |
| 向いている場面 | 文章を貼って訳したいとき | 海外サイトを見ながら読みたいとき |
| 使う場所 | <https://poke.apextox.dpdns.org> | Chrome・Edge・Vivaldi（Android版を含む） |
| 家の外 | 使えない（LAN内のみ） | 使える（サーバ不要） |

どちらも翻訳は **Google翻訳** に送ります（用語は置き換えてから送ります）。

## 翻訳サイト

1. 原文を左の欄に貼り、言語を選んで **翻訳**（`Ctrl+Enter`）を押します。
2. 右に訳文、下に「辞書で固定した用語」の一覧が出ます。
3. **用語だけ置き換え** にチェックすると、Google翻訳へ送らずに用語だけを日本語名に
   します。Showdown形式の型（`Garchomp @ Choice Scarf` など）に向いています。

## 拡張機能

見ているページの段落の下に日本語訳を差し込みます（対訳表示）。原文のリンクや
書式はそのまま残ります。

1. 翻訳サイトの下にある **拡張機能（zip）** をダウンロードして展開します。
2. ブラウザの拡張機能の管理画面（Vivaldi は `vivaldi://extensions`）で
   **デベロッパーモード** を有効にし、**パッケージ化されていない拡張機能を読み込む**
   で展開したフォルダを選びます。
3. 訳したいページでツールバーの **ポケモン翻訳** ボタン（PCは `Alt+T`）を押します。
   もう一度押すと「訳のみ」→「原文のみ」→「対訳」と切り替わります。

スクロールで増える投稿も自動で訳します。Showdown形式の型の欄は、用語だけを
置き換えて下に表示します。辞書が更新されたら、zipを取り直して読み込み直します。

## 用語を足したいとき

俗称や対戦用語は `stacks/poke-translate/custom-terms.json` に足します（管理者作業）。
仕組みと書き方は `stacks/poke-translate/README.md` を参照してください。
