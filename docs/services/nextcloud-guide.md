# Nextcloudの使い方（利用者向け）

更新日: 2026-09-13。**招待された利用者向けのマニュアルです。** 管理者向けの設定・アプリ一覧は[Nextcloudと追加アプリ](nextcloud.md)、ログインそのものは[共通ログインの使い方](identity.md)を参照してください。

## 入口とログイン

| もの | 値 |
| --- | --- |
| 入口 | <https://nextcloud.apextox.dpdns.org>（家庭内LANから） |
| ログイン | 共通ログイン（Authentik）。招待されたアカウントだけ |
| パソコン | ブラウザー、または公式デスクトップアプリ（Windows・macOS） |
| スマートフォン | 公式Nextcloudアプリ（[Androidの設定](#android)） |

ログイン画面でメールアドレス（またはユーザー名）を入れると、共通ログインの画面へ進みます。パスキーを使うとパスワードなしで入れます。**自宅のLANの外からは今のところ使えません。** 外出先用のVPNは準備中です。

## 今使える機能

| 機能 | 場所 | できること |
| --- | --- | --- |
| ファイル | **ファイル** | アップロード・ダウンロード・フォルダー・名前変更・コピー |
| 共有 | ファイルの **共有** | 利用者を指定して共有、リンク共有（LAN内の人だけ開けます） |
| 履歴・復元 | ファイルの **詳細** | 過去のバージョンを見る・戻す、消したファイルは**ゴミ箱**から戻す |
| 写真 | **写真** | アップロードした画像の一覧（スマホの自動アップロード先にも使えます） |
| プレビュー | ファイルを開く | PDF・画像・テキストをブラウザーで表示 |
| 文章編集 | **Text** | Markdown（`.md`）をその場で編集。`docs`は共有のMarkdown置き場（手順書サイトはGitの`docs/`から配備） |
| 予定 | **Calendar** | カレンダー作成・共有・通知 |
| TODO | **Tasks** | リストとタスク、期限、優先度 |
| 印刷 | ファイルの **…** | **「印刷」**でCanon TS8430へ直接印刷（下記） |
| タグ編集 | 音楽ファイルの **…** | 曲名・アーティスト・アルバム等を編集（MusicBrainz検索つき） |
| 端末へ送信 | ファイルの **…** | **「LocalSendで送る」**で同じLANの端末へ送信（下記） |
| 通知・検索・コメント・タグ | 画面右上など | 更新の通知、ファイル検索、コメント、タグ付け |
| 2段階認証 | 個人設定 → セキュリティ | TOTPアプリの登録、バックアップコード |

Talk・Deck・Notes・連絡先などのアプリはまだ入っていません。必要になったら管理者に相談してください。

## フォルダーの使い分け

| フォルダー | 入れるもの | 連携先 |
| --- | --- | --- |
| ホーム（自分のファイル） | 自由に使う書類・写真 | — |
| `books` | PDF・電子書籍（作品ごとのフォルダー） | [Kavita](https://kavita.apextox.dpdns.org) で読む |
| `music` | MP3などの音楽 | [Navidrome](https://navidrome.apextox.dpdns.org) で聴く。`music/YouTube` はMeTubeの取り込み先 |
| `docs` | Markdownの共有置き場 | 手順書サイトは[Shake Lab Docs](https://docs.apextox.dpdns.org)（原稿はGitの`docs/`） |
| `inbox` | スマホからLocalSendで送ったファイルの着地先 | 手動で好きな場所へ移動 |

**`books`・`music`・`docs`・`inbox` は、Nextcloudにログインできる人なら全員に表示されます。** ファイルの追加・移動・削除もできます。見えないときは一度ログインし直し、それでも出ない場合は管理者に相談してください（[アクセス権限](../operations/nextcloud-permissions.md)）。

## スマホからファイルを送る（LocalSend）

写真や書類をNextcloudへ入れる一番簡単な方法です。同じWi-Fi内の端末からmedia-01の受信機へ送ると、Nextcloudの `inbox` に着地します。

1. スマホ（またはパソコン）に公式 **LocalSend** アプリを入れます（Google Play・App Store・F-Droid。パソコン版は <https://localsend.org>）。
2. 受信機と同じWi-Fi（家庭内LAN）につなぎます。
3. アプリを開き、デバイス一覧から **`media-01`** を選びます。
4. 初回だけ証明書の確認が出ます。内容を確認して信頼します（受信機を再起動すると、また確認が出ます）。
5. 送りたいファイルを選んで送信します。
6. Nextcloudの **inbox** に `送信元/年/月/` の形で入ります。本・音楽・手順書に使うものは `books`・`music`・`docs` へ移動してください。

うまく見つからないとき:

- 同じWi-Fiにいるか確認します。別のSSID・ゲスト用Wi-Fi・テザリングでは見つかりません。
- アプリで再読み込み（引っ張って更新）をします。
- ルーターの「端末間通信の遮断（プライバシーセパレーター）」が有効だと見つかりません。無効にしてください。
- URLを手で指定する必要はありません（自動検出です）。どうしても手動の場合は `localsend.apextox.dpdns.org:53317` を使います（ブラウザーで開いても404で正常です）。

## Nextcloudからファイルを送る（共有・保存）

### 同じNextcloudの人へ共有する

1. ファイルのメニュー（**…**）→ **共有**
2. 相手の名前を入れて選びます（同じNextcloudのアカウントを持つ人だけ）
3. 閲覧だけか、編集もできるかを選んで共有します

### リンクで共有する

1. 共有メニュー → **リンク共有** → **リンクをコピー**
2. 必要ならパスワードや有効期限を付けます
3. **このリンクが開けるのは家庭内LANの中だけです。** 名前が内部IPを指しているため、メールやLINEで家の外の人へ送っても開けません（インターネット公開の入口は未構築）

### スマホ・パソコンへ保存する

- スマホ（公式アプリ）: ファイルを開いて **共有 → 保存／ダウンロード**、または他アプリへ送ります（LINE・メール添付など）
- パソコン（ブラウザー）: ファイルの **ダウンロード**。フォルダーはZIPでまとめて取れます
- パソコン（デスクトップアプリ）: 同期したいフォルダーを選ぶと、変更が自動で手元に反映されます

### 家の中の端末へ送る（「LocalSendで送る」）

Nextcloudのファイル一覧から、同じLANにいる端末のLocalSendへ直接送れます。media-01の送信機能が相手を探して送ります。

1. 送り先の端末で **LocalSendアプリを開きます**（受信できる状態にしておく）。
2. Nextcloudのファイル一覧で、送りたいファイルの **…** → **LocalSendで送る** を選びます。
3. 表示された端末の一覧から、送り先を選びます。
4. 送り先の端末に受信の確認が出ます。**受け取る**を押すと保存されます。

| うまくいかないとき | 確認すること |
| --- | --- |
| 端末が一覧に出ない | 送り先でLocalSendを開いているか、同じWi-Fiか。少し待って再試行 |
| 送信が失敗する | 送り先のLocalSendで受信の確認を押したか。もう一度試す |
| 送り先がパソコンの場合 | LocalSendアプリを起動し、受信できる状態にする（同じ手順） |

逆向き（端末 → Nextcloud）は、上の「スマホからファイルを送る（LocalSend）」で `inbox` に着きます。

### 向きの整理

| やりたいこと | 使うもの |
| --- | --- |
| 端末 → Nextcloudへ入れる | 上の「スマホからファイルを送る（LocalSend）」、またはアプリ/ブラウザーのアップロード |
| Nextcloud → 家の中の人・端末へ | 共有（リンク／相手指定）・ダウンロード・**端末のLocalSendへ共有** |
| 家の外の人へ送る | 今は不可（公開の入口は準備中）。リンクはLANの中だけで開きます |

## 他のサービスとの連携

Nextcloudは単体で使えますが、同じ保存領域・同じアカウントで次のサービスとつながっています。

| サービス | つながり方 | 使いどころ |
| --- | --- | --- |
| [共通ログイン](identity.md)（Authentik） | 同じアカウントでHomarr・Nextcloud・Vaultwardenに入れる | パスキー登録、パスワード再設定 |
| [Homarr](https://homarr.apextox.dpdns.org) | サービスの入口。Nextcloudのタイルあり | 最初に開く場所 |
| [Kavita](https://kavita.apextox.dpdns.org) | `books`フォルダーを読む | 本・PDF・電子書籍 |
| [Navidrome](https://navidrome.apextox.dpdns.org) | `music`フォルダーを再生（ブラウザーは共通ログインで自動ログイン） | 音楽 |
| [MeTube](https://metube.apextox.dpdns.org)（media-01への配備は未了） | 取り込んだ音声が`music/YouTube`へ入る | URLから音声を取り込む |
| [LocalSend](../development/D06-localsend.md) | 端末から`inbox`へ受信／Nextcloudの「…」→「LocalSendで送る」で端末へ送信 | 端末とNextcloudの受け渡し（`localsend.apextox.dpdns.org:53317`） |
| [プリンター](printer.md)（CUPS） | ファイルの「…」→「印刷」 | Nextcloudのファイルを印刷 |
| [Vaultwarden](vaultwarden.md) | 同じ共通ログインで使うパスワード管理 | Nextcloudのログイン情報も保管 |
| [Shake Lab Docs](https://docs.apextox.dpdns.org) | Gitの`docs/`をサイトとして公開 | 手順書の閲覧 |

## MP3タグを編集する（MP3タグ編集）

`music` フォルダーのMP3は、Nextcloud上でタグを編集できます。これはNextcloud標準の「タグ」（お気に入りなどの色付きタグ）とは別の、**ファイルの中に書き込むID3タグ**を編集する機能です。メニューでは **MP3タグを編集** と表示されます。

1. `music` のMP3の **…** → **MP3タグを編集** を選びます。
2. フォームに曲名・アーティスト・アルバムなどを入れます。**MusicBrainzで検索** を押すと候補が出て、押すと入力欄に入ります。**コメント（備考）** 欄には「vs ○○」など曲名で分からない情報を自由に書けます。
3. **保存** を押します。変更前のタグはmedia-01側にバックアップされます。

Navidromeへの反映は通常1時間以内です（Navidromeの定期スキャン）。編集できるのは `music` にあるMP3だけです。

### MP3タグ（ID3）の主な項目

| 項目 | タグ | 使われ方 |
| --- | --- | --- |
| 曲名 | TIT2 | Navidromeの曲名 |
| アーティスト | TPE1 | 曲のアーティスト |
| アルバム | TALB | アルバムのまとまり |
| アルバムアーティスト | TPE2 | アルバムの所属（Navidromeのアルバム表示） |
| トラック/ディスク番号 | TRCK / TPOS | 曲順。Disc Nフォルダの整理にも使用 |
| 年 | TDRC | 表示・並び替え |
| ジャンル | TCON | ジャンル表示・絞り込み |
| 作曲者 | TCOM | 作曲者（ゲームBGMの作曲者など） |
| コメント | COMM | 自由記入の**備考欄**。「vs ○○」など曲名で分からない情報に |
| グルーピング | TIT1 | 「バトルBGM」などの分類 |
| サブタイトル | TIT3 | 補足（「vs チャンピオン」など） |
| 歌詞 | USLT | 埋め込み歌詞。`.lrc`ファイル（サイドカー）でも可 |
| MusicBrainz ID | UFID / TXXX | 照合用。通常は触らない |

**備考・別名について**: 「別名」専用の標準タグはありません。実務では**コメント（COMM）**に「→vs チャンピオン」のように書くか、**サブタイトル（TIT3）**に補足を入れる方法が一般的です。NavidromeのWeb画面は曲名・アーティスト・アルバム・ジャンル中心の表示で、コメントは表示されません（タグ編集画面や他のプレイヤーで確認できます）。

## 印刷する

**パソコンのブラウザー**: ファイル一覧で印刷したいファイルの **…**（または右クリック）→ **印刷**。PDF・PNG・JPEG・テキストに対応し、今は1部・カラーで出ます。プリンターがスリープ中だと始まるまで少し待つことがあります。

**スマートフォンや、Webを使わない場合**: ファイルを開いて端末の **共有 → 印刷**（Canon PRINTアプリやAirPrint）を使います。Nextcloudのアプリ自体には印刷ボタンがありません。

詳しい条件は[プリンター（Canon TS8430）](printer.md)を参照してください。

## Android

### 公式Nextcloudアプリ

1. Google PlayまたはF-Droidで **Nextcloud** をインストールします。
2. アプリの「アカウントを追加」で、サーバーアドレスに `https://nextcloud.apextox.dpdns.org` を入力します。
3. **「ブラウザーでログイン」** を選びます。開いた共通ログインでサインインし、最後に「アクセスを許可」を押します。
4. ファイル一覧が出れば完了です。左上のメニューから **写真**・**自動アップロード** などを開けます。

| やりたいこと | アプリでの場所 |
| --- | --- |
| ファイルをアップロード | フォルダーを開き、**＋** を押す |
| 共有 | ファイルのメニュー → **共有** |
| オフラインで見る | ファイルのメニュー → **オフラインで使用可能** |
| カメラの自動アップロード | 設定 → **自動アップロード**（Wi-Fiのみ推奨） |
| `.md`の編集 | ファイルを開いて **Text** で編集。大きな編集はパソコン推奨 |

### カレンダー・タスクの同期（DAVx⁵）

1. F-Droid（またはGoogle Play）で **DAVx⁵** をインストールします。
2. アカウントを追加し、種類で **Nextcloud** を選ぶか、URLに `https://nextcloud.apextox.dpdns.org` を入力します。
3. ログインはブラウザーの共通ログイン、またはアプリパスワードを使います（作成できない場合は管理者へ）。
4. 同期するものを選びます（Calendar・Tasks）。必要なら **OpenTasks** などタスク表示アプリも入れます。

連絡先アプリはサーバーに入れていないため、DAVx⁵に連絡先の項目が出ないことがあります。

### Androidからの印刷

Nextcloudアプリでファイルを開き、**共有 → 印刷** を選びます。印刷先に **Canon TS8430** が出ない場合は、Canon PRINTアプリを入れるか、管理者に相談してください。

### うまくいかないとき

| 症状 | 確認すること |
| --- | --- |
| ログイン画面が出ない・ループする | 先にパソコンで `https://nextcloud.apextox.dpdns.org` にログインできるか確認。できなければ管理者へ |
| 接続できない | 家のWi-Fiにつないでいるか。外出先からはまだ使えません |
| `books`・`music`・`docs`・`inbox` が見えない | 一度ログインし直す。それでも出ない場合は管理者へ（再配備が必要） |
| アプリパスワードを作れない | 共通ログインの方式によっては作成できないことがあります。管理者へ |
