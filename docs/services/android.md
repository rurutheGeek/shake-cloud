# Android VMの画面を使う（RDP）

> **更新日** 2026-09-26 ・ **区分** 利用ガイド ・ **読む人** 利用者

**状態**: 稼働中。`android-01`（`192.168.10.104`）で Waydroid の Android 画面が動いており、**RDP で画面を操作できます**。

クラウドVM `android-01` の上で Android（Waydroid）が動いています。この画面には **RDP（リモートデスクトップ）** で入って、マウス・キーボードで直接操作できます。専用のアプリや Web 化はなく、手持ちの RDP クライアントからつなぐだけです。

| | 値 |
| --- | --- |
| つなぎ先 | `192.168.10.104:3389` |
| 方式 | RDP（weston のRDPバックエンド） |
| 画面の消灯 | なし（`idle-time=0`。放置しても消えない） |
| 使える範囲 | 家のLAN内のみ。外出先からは[VPN](../architecture/vpn.md)経由 |

## 1. 何ができるか

Android の画面をそのまま表示し、マウス・キーボードで操作できます。アプリの起動やログインなど、実機を触るのと同じことができます。

画面が固まった（FROZEN）ときは自動で復帰する仕組みが入っているので、基本は放置で戻ります。それでも直らないときは開発者に連絡してください。

## 2. どの利用者に影響するか

画面は1つを共有します。同時に別の人が操作すると取り合いになるので、使うときは声をかけてください。

## 3. 接続の準備

RDP クライアントを1つ用意します。OSごとの定番は次のとおりです。

| OS | クライアント | 入れ方 |
| --- | --- | --- |
| Windows | リモートデスクトップ接続（標準搭載） | 追加不要。「リモート デスクトップ接続」を検索して起動 |
| macOS | Windows App（旧 Microsoft Remote Desktop） | App Store から入れる |
| Linux | Remmina | `sudo apt install remmina remmina-plugin-rdp` |
| iOS / Android | Windows App | 各ストアから入れる |

## 4. 具体的な入力例

### Windows（標準のリモートデスクトップ接続）

1. 「リモート デスクトップ接続」を起動する。
2. 「コンピューター」に `192.168.10.104:3389` を入れて「接続」。
3. Android の画面が出たら、マウス・キーボードでそのまま操作する。

### macOS（Windows App）

1. Windows App を開き、右上の「＋」→「Add PC」。
2. 「PC name」に `192.168.10.104` を入れて保存。
3. 追加されたアイコンをダブルクリックして接続する。

### Linux（Remmina）

1. Remmina を開き、左上の「＋」で新規プロファイル。
2. 「Protocol」を **RDP**、「Server」を `192.168.10.104:3389` にして保存。
3. プロファイルをダブルクリックして接続する。

外出先から使うときは、先に[VPN](../architecture/vpn.md)につないでから同じ手順でつなぎます。

## 5. うまくいかないとき

| 症状 | 見るところ |
| --- | --- |
| 接続できない | 家のLAN内にいるか（外出先なら[VPN](../architecture/vpn.md)が必要）。VMが起動しているか |
| つながるが画面が真っ暗・固まる | 少し待つと自動復帰する。数分たっても直らなければ開発者へ連絡 |
| ログインアプリの操作 | 認証情報は別途受け渡し。詳細は開発者へ |

環境の中身（Waydroid・自動復旧の仕組みなど）は利用者が触る必要はありません。技術的な詳細は開発者向けの環境構築依頼書にまとまっています。
