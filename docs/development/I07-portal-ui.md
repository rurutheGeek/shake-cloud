# I07 クラウドポータルのUI改善

> **更新日** 2026-10-03 ・ **区分** 開発計画 ・ **読む人** 開発者

**区分**: 既存機構の改善 ・ **状態**: **ファビコンと、タグの表示・絞り込み・作成時の指定を実装（2026-10-03）。cloud-01 へは未配備。** 作成後のタグ変更は未実装（APIの追加が要る。下の5）。3 は提案で、採否は未決。

## 目的・現状・配備先

クラウドVMが増える（[配置と命名の再編](../architecture/placement-naming.md)で、アプリと開発VMをクラウドVMへ寄せる）ので、ポータルを見分けやすく・探しやすくする。配備先は cloud-01 のクラウドAPI（`cloud/api/internal/server/web/`。Goのバイナリへ埋め込み）。

現状（2026-10-03）:

- **ファビコンが無い。** ブラウザーのタブで、ポータル・VMのコンソール・ヘルプが見分けられない。
- メニューが14項目、横1列に並んでいる（概要・ヘルプ・インスタンス・ボリューム・セキュリティグループ・S3・データベース・関数・イメージ・ISO・SSH鍵・アクセスキー・操作履歴・管理設定）。
- インスタンス一覧は9列（名前・所有者・状態・IP・イメージ・構成・ディスク・セキュリティグループ・操作）で、用途（サービス／開発）で分かれていない。
- 配色は明・暗の両方に対応済み（`portal.css` の変数）。外部のライブラリは使っていない。

## 変更範囲と実装

1. **ファビコン（実装済み）。** 図柄は**空飛ぶ鮭**（shake＝鮭、cloud＝空）を**マテリアルデザイン**（平らな面・単純な形・影やグラデーション無し）で描く。水色の角丸の地に、白い翼のあるサーモン色の鮭。`/static/favicon.svg` として埋め込み、`index.html`・`console.html`・`help.html`・`message.html` の4枚すべてから参照する。地の色を持つので、明・暗どちらのタブでも同じ絵で見える。`/favicon.ico` は用意していない（開発機に画像変換の手段が無い。SVG のファビコンを読めない古いブラウザーではアイコンが出ない）。
2. **タブの題名（対応不要）。** コンソールの題名は既に「コンソール — <VM名>」になっていた（計画時の見落とし）。
3. **メニューのまとまり（提案）。** 14項目を「計算（インスタンス・ボリューム・セキュリティグループ・イメージ・ISO・SSH鍵）」「データ（S3・データベース・関数）」「アカウント（アクセスキー・操作履歴・管理設定）」の3つに見出しで分ける。URL（`#instances-view` など）は変えない。
4. **タグの表示・絞り込み・作成時の指定（実装済み）。** 用途のための専用の列は作らない。インスタンス一覧の名前の下に `Name` 以外のタグを並べ、タグを押すとそのタグで絞り込む（検索欄がタグも探す）。作成フォームに「タグ（任意）」の欄を足し、`Purpose=dev, Team=home` の形で付けられる。用途はこのタグで表す。APIは変えていない。
5. **作成後のタグ変更（未実装）。** APIにタグを更新する操作が無い（Terraform Provider も、タグを変えるとインスタンスを作り直す）。計画時の「APIは変えない」は誤りだった。追加するなら openapi・API・client・CLI・Provider・ポータルを揃える。`Name` はゲストのホスト名なので、変更の扱いを決める必要がある。それまで、既存のVMにタグを付ける手段は無い。

1〜4 に API の変更は無い（openapi・client・cli・provider は触らない）。外部のライブラリやアイコン集は足さない。

## 依存と並列作業

- 配置の再編とは独立に進められる。
- 開発は dev-b の作業ツリーで行う。配備は cloud-01 のクラウドAPIの入れ替えで、数秒の再起動がある（動いているVMには影響しない）。dev-b 自体は止めない。

## 検証・完了条件

- `cloud/api` の `go test ./...`（4枚のHTMLがファビコンを参照し、`/static/favicon.svg` と `/favicon.ico` が200を返すことをテストに足す）
- ポータルで付けたタグが CLI（`--tag`）で付けたものと同じに見えること、タグでの絞り込みが効くこと
- 実機で、明・暗の両方のタブにファビコンが出ること、コンソールのタブが見分けられることをブラウザーで確認する
- [引き継ぎ台帳](../operations/handover.md)を更新する
