ヘルプ

    
よく使う操作の手順です。詳しい運用は管理者の手順書も参照してください。

    

      Windows 11 をISOからインストールする
      
    
        
  1. 「ISO」に Win11 のISO（OS=Windows 11） と virtio-win のISO があるのを確認します（共有ISOにあればそのまま使えます）。
    2. 
        
  2. 「インスタンスを作成」→ 作成方法「ISOからインストール」。インストールISO=Win11、ゲストOS=Windows 11、ドライバISO=virtio-win、ルートディスクは64 GiB以上、メモリは4096 MiB以上にします。
    3. 
        
  3. 起動したら一覧の「コンソール」を開きます。インストール先の一覧が空のときは「ドライバーの読み込み」→ virtio-win のCDの viostor\w11\amd64 を開き、「Red Hat VirtIO SCSI controller」を選んでインストールします（このポータルが作るディスクは virtio0 のため。vioscsi は scsi0 のディスク用で、こちらでは見つかりません）。
    4. 
        
  4. ネットワークも使うなら、同じ手順で NetKVM\w11\amd64 も読み込みます。
    5. 
        
  5. インストール後、一覧の「IP」列にある割り当てIPをWindows側に設定します。または「ISO」の cloudbase-init をCDで開いてMSIを実行し、再起動するとホスト名とIPが自動設定されます。
    6. 
      

    

    

      電源操作ができない／再起動が終わらない
      
作成・起動・停止・再起動・削除のいずれかが処理中の間は、一覧の状態に「〜処理中…」と表示され、別の電源操作は受け付けません。処理中にボタンを押すと理由を案内します。完了まで待ってください。Windowsなどguest agentが無いゲストでACPIに応答しない場合は、再起動は自動で強制リセットに切り替わります。

    

    

      コンソールが開かない
      
ブラウザがポップアップをブロックした場合、画面に表示される「〜のコンソールを開く」リンクを押してください。リンクは5分で無効になります。その場合はもう一度「コンソール」を押して発行し直します。

    

    

      IPアドレスはどこ？／ネットワークにつながらない
      
一覧の「IP」列が割り当てられた固定IPです。Linuxのイメージは起動時に自動設定されます。WindowsやISOから入れたゲストは、そのIPをゲスト側で設定してください（「Windows 11をISOからインストールする」の手順5）。SSHやRDPで入るには、そのポートを許可するセキュリティグループをVMに付けてください。

    

    

      削除する前に
      
 VMを削除するとルートディスクも消えます。接続済みの追加ボリュームは切り離されて残ります。消したくないデータはボリュームかS3へ。削除の確認画面に対象の名前・ID・所有者が出ます。
