# 入口の後ろのホストの内部CA

`dns.yaml` の `edge.backends` に書いたホストは、自分の Caddy の内部CAで出した証明書で
入口（`edge.host`）からの中継を受けます。入口はここの `<ホスト名>.crt` で相手を確かめます。

- 中身は**公開してよい証明書**（CAの秘密鍵は各ホストの中だけにあります）。
- 各ホストの配備（`tls_proxy` ロール）が取ってきて、ここへ書きます。**手で編集しません。**
- ホストを作り直すとCAが変わります。そのホストを配備し直して、変わったファイルをコミットし、
  入口（`edge.yml`）を配備し直します。入口は古いCAの相手へは中継しません（502）。

手順は `docs/operations/edge.md`。
